# ParentPlus
Parent Companion

ParentPlus is a foundation for parents/guardians, independent coaches and academies
to manage authorised learning relationships. The intended product is broader than
the current local implementation.

Start with [Shared Project Context](docs/PROJECT_CONTEXT.md) for product framing,
canonical document ownership and the reading order for any assistant.
Use [Agent Handoff](docs/AGENT_HANDOFF.md) to resume a specific repository snapshot,
[Build Progress](docs/BUILD_PROGRESS.md) for implementation status and
[Quality Evidence](docs/QUALITY_EVIDENCE.md) for what was actually verified.

Codex loads [AGENTS.md](AGENTS.md); Claude Code loads [CLAUDE.md](CLAUDE.md).
Other assistants need explicit repository access or supplied documents. There is
no automatic transfer of conversations or unpublished local changes.

The [web README](apps/web/README.md) contains framework starter commands; it is not
proof that live authentication, hosted data or the complete product is configured.
