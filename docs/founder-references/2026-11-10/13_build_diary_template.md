# 13. Build diary template

**In short:** after every working session you get this note. It takes 5 minutes to read, and needs no technical knowledge.

---

## Build diary: [date], Stage [n] [name]

**Today in one line:** [what's now possible that wasn't this morning]

**Try it** ([preview link])
1. ...
2. ...
3. ...

**What I built and why**
- [plain description] (feature [M2-xx]) because [reason]

**Decisions I made**
- [decision]: [why]. Reversible? [yes/no]

**What's next**
- [next story], expected [day]

**What I need from you**
- [request], by [date]. If there's no answer, I'll [default action, never for cost or privacy decisions]

**Health check**
- Automatic checks: [green/red]. Database security tests: [n] of [n] passing
- Free-tier usage: database [x]%, files [x]%, emails today [x] of 100, AI [x]% of limit
- Risks moved: [none / R#: what changed]

**New word of the day:** [term]: [one-sentence explanation]
